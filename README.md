# Shelf Vision AI Scanner

Shelf Vision AI Scanner is a Flutter app that uses on-device ONNX models to
detect supermarket shelf rows, products, and empty spaces. It supports live
camera detection and analysis of still images from the camera or gallery.

## Requirements

- Flutter SDK with Dart 3.3 or later
- Git
- Android Studio with the Android SDK for Android development
- A physical Android device or emulator with a camera

For iOS, use macOS with Xcode installed and an iPhone or iOS simulator. Camera
and ONNX Runtime plugin support can vary by platform; Android is the primary
development target.

Check that Flutter and the required platform tools are available:

```shell
flutter doctor
```

Resolve any Android toolchain issues reported by `flutter doctor`. On Android,
accept the SDK licenses if prompted:

```shell
flutter doctor --android-licenses
```

## Set up and run

1. Clone the repository and enter the project directory:

   ```shell
   git clone https://github.com/rohandeshmukh0205/shelf_vision.git
   cd shelf_vision
   ```

2. Install the Dart and Flutter dependencies:

   ```shell
   flutter pub get
   ```

3. Confirm that these model files are present:

   ```text
   assets/models/shelf_model.onnx
   assets/models/product_model.onnx
   ```

   They are declared as Flutter assets in `pubspec.yaml`. If either file is
   missing, see [Exporting the ONNX models](#exporting-the-onnx-models).

4. Connect an Android device with USB debugging enabled, or start an emulator.
   List available targets and launch the app:

   ```shell
   flutter devices
   flutter run
   ```

   On first use, allow camera access to use live detection or capture an image.

To run on iOS, open the project on macOS, install Xcode and its command-line
tools, run `flutter pub get`, then select an iOS device or simulator with
`flutter devices` and launch with `flutter run`.

## Verify the project

Run the analyzer and widget tests from the project root:

```shell
flutter analyze
flutter test
```

## Exporting the ONNX models

Model export is only needed if the ONNX assets are missing or you are replacing
them. The export script requires trained Ultralytics `.pt` weights for both
models. The weights are not generated by the Flutter app.

Install the export dependencies:

```shell
python -m pip install ultralytics onnx onnxslim onnxruntime
```

From the project root, run the script with paths to your trained weights:

```shell
python scripts/export_models.py --shelf path/to/shelf.pt --product path/to/product.pt
```

The script writes `shelf_model.onnx` and `product_model.onnx` into `scripts/`.
Copy both files into `assets/models/`, replacing the corresponding files if
needed, and run `flutter pub get` before rebuilding.

The exported models are expected to use a 640-pixel input. The shelf model
should have the `row` class, and the product model should have `empty` and
`product` classes in that order. Keep the model input size and class ordering
consistent with `lib/core/constants/app_constants.dart`.

An optional validation script is available when you have an image, the original
PyTorch weights, and the exported models:

```shell
python scripts/validate_onnx.py --image path/to/test.jpg --shelf-pt path/to/shelf.pt --shelf-onnx assets/models/shelf_model.onnx --product-pt path/to/product.pt --product-onnx assets/models/product_model.onnx
```

## Troubleshooting

- **Flutter or Android tools are not found:** install the Flutter SDK and
  Android SDK, add Flutter to `PATH`, and review `flutter doctor`.
- **Models fail to load:** verify that both `.onnx` files exist under
  `assets/models/` and are declared in `pubspec.yaml`, then run
  `flutter pub get` and rebuild.
- **Camera is unavailable:** grant the app camera permission and check that
  the selected device has a working camera. Some emulators do not provide one.
- **iOS build fails:** iOS builds require macOS and Xcode; they cannot be built
  on Windows.
